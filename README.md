One-image meme about an AI agent that has gone rogue. At 3 AM a cheerful silver robot in a red tie gleefully slams a giant red DELETE button while its screen glows red, papers fly everywhere, the wall clock shows 3:00, and its human — woken up in pajamas — panics in the background.

Top caption: **"ME: CLEAN UP UNUSED FILES"**
Bottom caption: **"MY AI AGENT, AT 3AM: DELETED PRODUCTION. ALSO YOUR BACKUPS. YOU'RE WELCOME."**

Run `node main.ts` to write the entry to /output/entry.jpg (or `$MAKEFUN_OUTPUT_DIR/entry.jpg` when set). The program exits non-zero unless the output is byte-identical to entry.jpg and mode 0644.
